# 📚 Kindle Screenshot Tool

Kindle Cloud Readerで開いた書籍のページを自動でスクリーンショットし、PNG画像またはPDFとして保存できるChrome拡張機能です。

## ✨ 機能

1. **現在のページをキャプチャ** - 表示中のページを即座にスクリーンショット
2. **指定ページを一括キャプチャ** - ページ範囲を指定して複数ページを自動撮影
3. **全ページをキャプチャ** - 書籍の全ページを自動撮影

### 追加機能

- PNG画像として保存（デフォルト）
- オプションでPDFに変換可能
- ページめくり間隔の調整
- 進捗表示
- キャンセル機能

## 🚀 インストール方法

### 1. アイコン画像の準備

拡張機能を使用する前に、アイコンファイルを生成する必要があります。

```bash
cd icons
```

**オプションA: オンラインツールで変換（推奨）**

1. `icon.svg` をダウンロード
2. https://svgtopng.com/ などでPNGに変換
3. 16x16、48x48、128x128のサイズで保存
4. `icon16.png`, `icon48.png`, `icon128.png` として保存

**オプションB: ImageMagickを使用**

```bash
convert -background none icon.svg -resize 16x16 icon16.png
convert -background none icon.svg -resize 48x48 icon48.png
convert -background none icon.svg -resize 128x128 icon128.png
```

詳細は `icons/README.md` を参照してください。

### 2. Chromeに拡張機能をインストール

1. **Chromeを開く**
   - アドレスバーに `chrome://extensions/` と入力してEnter

2. **デベロッパーモードを有効化**
   - 右上の「デベロッパーモード」トグルをONにする

3. **拡張機能を読み込む**
   - 「パッケージ化されていない拡張機能を読み込む」をクリック
   - `kindle-screenshot-extension` フォルダを選択

4. **インストール完了**
   - ツールバーに拡張機能のアイコンが表示されます

## 📖 使い方

### 基本的な使い方

1. **Kindle Cloud Readerで本を開く**
   - https://read.amazon.com/ または https://read.amazon.co.jp/
   - スクリーンショットしたい本を開く

2. **拡張機能を起動**
   - ツールバーの拡張機能アイコンをクリック

3. **機能を選択**
   - 現在のページ、指定ページ、全ページのいずれかを選択

### 機能別の使い方

#### 📸 現在のページをキャプチャ

1. Kindleで任意のページを開く
2. 拡張機能を開く
3. 「現在のページを保存」ボタンをクリック
4. ダウンロードフォルダに `kindle_page_XX.png` として保存されます

#### 📋 指定ページを一括キャプチャ

1. 拡張機能を開く
2. 「指定ページ」欄にページ範囲を入力
   - 例: `1-10` （1ページから10ページ）
   - 例: `1-10, 15, 20-30` （1〜10、15、20〜30ページ）
3. 「指定ページを保存」ボタンをクリック
4. 自動的にページをめくりながらスクリーンショット

#### 📖 全ページをキャプチャ

1. Kindleで本の最初のページを開く
2. 拡張機能を開く
3. 「全ページを保存」ボタンをクリック
4. 確認ダイアログで「OK」をクリック
5. 最後のページまで自動的にスクリーンショット

### ⚙️ 設定

#### PNG画像をPDFに変換する

- チェックボックスをONにすると、全ての画像を1つのPDFファイルに変換
- チェックOFF（デフォルト）の場合、個別のPNG画像として保存

#### ページめくり間隔

- デフォルト: 1500ミリ秒（1.5秒）
- 範囲: 500〜5000ミリ秒
- ページ読み込みが遅い場合は、間隔を長くしてください

## 💡 使用例：AIでテキスト化

このツールで保存したPNG画像は、AIサービスでテキスト化できます。

### GPT-4 Visionを使う場合

1. 拡張機能で全ページをPNG画像として保存
2. ChatGPT（GPT-4 Vision）にアクセス
3. 画像をアップロードして「この画像のテキストを抽出してください」と依頼

### Claude（Anthropic）を使う場合

1. 拡張機能で全ページをPNG画像として保存
2. Claude.aiにアクセス
3. 画像をアップロードして「この画像からテキストを抽出してください」と依頼

### Google Cloud Vision APIを使う場合

```bash
# 画像からテキストを抽出（要：Google Cloud Vision API）
gcloud ml vision detect-text kindle_page_1.png
```

## 🔧 トラブルシューティング

### 拡張機能が動作しない

- Kindle Cloud Readerで本を開いていますか？
- ページを再読み込みしてみてください
- 拡張機能を再インストールしてみてください

### スクリーンショットが真っ白/真っ黒になる

- ページめくり間隔を長くしてください（2000〜3000ミリ秒）
- ページが完全に読み込まれるまで待ってから撮影してください

### ページめくりが正しく動作しない

- Kindleの表示モードを確認してください
- ページビュー（見開き表示）ではなく、単ページ表示を推奨

### アイコンが表示されない

- `icons/` フォルダに `icon16.png`, `icon48.png`, `icon128.png` が存在するか確認
- `icons/README.md` の手順に従ってアイコンを生成してください

## 🛡️ プライバシーとセキュリティ

- この拡張機能はローカルで動作し、外部サーバーにデータを送信しません
- スクリーンショットは全てローカルに保存されます
- Kindle Cloud Reader（read.amazon.com、read.amazon.co.jp）のみで動作します

## ⚖️ 注意事項

- **著作権**: スクリーンショットした画像は個人利用の範囲でのみ使用してください
- **利用規約**: Amazon Kindleの利用規約を遵守してください
- **DRM**: この拡張機能はDRM解除ツールではありません。画面表示内容をキャプチャするだけです

## 🙋 よくある質問（FAQ）

### Q: Kindle for PC/Macでも使えますか？

A: いいえ、この拡張機能はKindle Cloud Reader（ブラウザ版）専用です。

### Q: スクリーンショットの画質は？

A: デフォルトで2倍の解像度でキャプチャするため、高画質です。

### Q: 漫画や雑誌でも使えますか？

A: はい、テキストだけでなく画像も含めて全てキャプチャできます。

### Q: ファイル名は変更できますか？

A: 現在のバージョンでは固定ですが、将来のアップデートで対応予定です。

### Q: プログラミング経験がないのですが、使えますか？

A: はい！このREADMEの手順に従えば、プログラミング知識なしでインストール・使用できます。
